# Dominio (lenguaje ubicuo)

Acá definimos **qué significa cada concepto**, sus reglas y sus límites.

## Dominios

- `usuario`: identidad y datos del usuario.
- `tipo de servicio`: clasificación (ej: consulta, instalación, mantenimiento).
- `servicio`: lo que se ofrece (pertenece a un tipo).
- `evento`: una ocurrencia/agenda (relaciona usuario y servicio).
- `método de pago`: cómo paga un usuario.
